## 3. DependencyGraph (依赖图) 结构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         DependencyGraph                                     │
│                     (按物理寄存器索引的数组)                                  │
│                                                                             │
│   PhysReg Index: 0      1      2      3      4      ...    N               │
│                    │      │      │      │      │             │              │
│                    ▼      ▼      ▼      ▼      ▼             ▼              │
│  ┌────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐ ┌────────────┐│
│  │ Head: NULL │ │ Head:InstA │ │ Head:InstC │ │ Head: NULL │ │ Head:InstE ││
│  │ next:NULL  │ │ next:InstB │ │ next:NULL  │ │ next:NULL  │ │ next:InstF ││
│  └────────────┘ │ next:InstD │ └────────────┘ └────────────┘ │ next:NULL  ││
│                 │ next:NULL  │                                └────────────┘│
│                 └────────────┘                                               │
│                                                                              │
│   示例说明:                                                                   │
│   - Reg 1: InstA 是生产者 → InstB → InstD 是消费者 (等待 Reg1 的值)           │
│   - Reg 2: InstC 是生产者，无消费者                                          │
│   - Reg 4: InstE 是生产者 → InstF 是消费者                                   │
│                                                                              │
│   当 InstA 完成时:                                                            │
│   1. pop(Reg1) → 返回 InstB，标记 InstB 的源寄存器就绪                         │
│   2. pop(Reg1) → 返回 InstD，标记 InstD 的源寄存器就绪                         │
│   3. clearInst(Reg1) → 清空头部                                              │
│   4. regScoreboard[Reg1] = true (标记为就绪)                                 │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 9. 冲刷 (Squash) 流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         doSquash(tid) 流程图                                │
│                                                                             │
│  假设: squashedSeqNum[tid] = 100 (冲刷到序列号 100，>100 的都要冲刷)             │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ instList[tid] 初始状态 (从尾部开始冲刷):                               │ │
│  │                                                                        │ │
│  │  Head → [sn=95] → [sn=98] → [sn=100] → [sn=102] → [sn=105] → [sn=110] │ │
│  │         └─────────────────────┘    └──────────────────────────────┘    │ │
│  │              保留                    冲刷 (seqNum > 100)                │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ 从尾部向前遍历:                                                         │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│      squash_it = instList[tid].end()                                        │
│      --squash_it  ← 指向 sn=110                                             │
│                                                                             │
│      while (squash_it != end() && (*squash_it)->seqNum > 100):              │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ 处理 sn=110:                                                           │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│      1. 检查是否在 IQ 中且未冲刷:                                             │
│         if (!squashed_inst->isSquashedInIQ())                               │
│                                                                             │
│      2. 从依赖图移除 (如果不是非推测指令):                                   │
│         for src_reg in squashed_inst.srcRegs:                               │
│           dependGraph.remove(src_reg, squashed_inst)                        │
│                                                                             │
│         ┌─────────────────────────────────────────────┐                     │
│         │ 移除前: Reg3: [Producer] → [sn=110] → [sn=120]                  │ │
│         │ 移除后: Reg3: [Producer] → [sn=120]                           │ │
│         └─────────────────────────────────────────────┘                     │
│                                                                             │
│      3. 清空依赖图头部 (目标寄存器):                                         │
│         for dest_reg in squashed_inst.destRegs:                             │
│           dependGraph.clearInst(dest_reg)                                   │
│                                                                             │
│      4. 标记冲刷状态:                                                        │
│         squashed_inst.setSquashedInIQ()                                     │
│         squashed_inst.setIssued()      ← hack，让指令流向 commit              │
│         squashed_inst.setCanCommit()                                        │
│         squashed_inst.clearInIQ()                                           │
│                                                                             │
│      5. 从 instList 移除:                                                    │
│         instList[tid].erase(squash_it--)                                    │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ 继续处理 sn=105, sn=102... 直到 sn=100 (seqNum <= 100 停止)              │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ 同时处理 nonSpecInsts:                                                 │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│      for (seqNum, inst) in nonSpecInsts:                                    │
│        if inst.seqNum > squashedSeqNum[tid]:                                │
│          nonSpecInsts.erase(seqNum)                                         │
│          iqStats.squashedNonSpecRemoved++                                   │
│                                                                             │
│  ┌───────────────────────────────────────────────────────────────────────┐ │
│  │ 通知 MemDepUnit 冲刷:                                                    │ │
│  └───────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
│      memDepUnit[tid].squash(squashedSeqNum[tid], tid)                       │
└─────────────────────────────────────────────────────────────────────────────┘
```
